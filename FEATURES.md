# G-O-D MOD - Complete Features Guide

## Overview
G-O-D MOD is a comprehensive gameplay enhancement mod for No Man's Sky that grants godlike powers to your player character. All features are automatically active when the mod is installed.

---

## Feature 1: INVINCIBILITY

### What it does:
- Your player character cannot be killed or damaged by any source
- Complete protection from all harm

### Protected against:
- ✅ Creature and animal attacks
- ✅ Extreme weather (toxic storms, extreme heat/cold)
- ✅ Radiation and toxic environments
- ✅ Underwater oxygen depletion
- ✅ Fall damage
- ✅ Sentinel attacks
- ✅ All environmental hazards
- ✅ Any other damage source

### Technical Details:
- Player health set to 99,999 (effectively infinite)
- All damage multipliers set to 0.0
- Environmental drain rates disabled
- Automatic and always active

## Installation Summary

The mod is ready to install. Just copy the entire `G-O-D-MOD` folder into:
```
No Man's Sky/GAMEDATA/MODS/G-O-D-MOD/
```

### Files Included:
- `MODINFO.XML` - Mod metadata
- `PlayerData.xml` - Invincibility & unlimited resources config
- `BuildingData.xml` - Unlimited building config
- `TechModifications.xml` - Max tech modifications config

## Troubleshooting

**Features not active?**
- Verify G-O-D-MOD folder is in GAMEDATA/MODS/
- Create a new save file
- Restart the game

**Game performance issues?**
- Check that all XML files are properly formatted
- Ensure no other conflicting mods
- Lower graphics settings if needed
